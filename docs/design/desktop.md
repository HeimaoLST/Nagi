## 原生窗口与布局

采用 Bee 外观及已批准的第一阶段可读性、动作层级与页面结构修正。尺寸均为 DIP。`workspace.go` 定义分栏，`view.go` 组装主面板，`navigation.go` 组装只读对话，`settings_page.go` 组装设置。

| 布局 | 当前结构及验收边界 |
| --- | --- |
| 工作台 | 透明侧栏置于外壳上，主面板留 4 的外边距和 1 的边框。侧栏包含 Bot 搜索、列表、新增和底部设置。普通侧栏默认 272，可调 180–420。分隔线可拖动及通过键盘操作。响应布局保留用户设置的栏宽。 |
| Bot 资料 | 从 1180 起完整侧栏、对话、资料同屏。900–1179 使用 56 宽头像条，资料栏最小 300。低于 900 使用带返回的应用内整页。分栏内用 X 关闭资料。资料栏默认 340，通常可调 280–440，也受可用空间约束。 |
| 对话区 | 恢复通知、阅读和 composer 共享居中的 768 最大列宽。页头横向内缩 16、纵向内缩 12，底部使用 1 DIP 分隔线。用户消息上限 752。分栏算法的中心预算为 516。C-4 要求 960 × 640 同时显示资料与对话时，净可编辑宽度至少 440。720 × 640 检查活动打开时 composer 仍可聚焦、输入和发送。 |
| 设置 | 常规侧栏宽 248，导航组左右内缩 8，行填满组。小于 640 的设置布局使用可换行顶部导航。侧栏和主面板之间使用单条细线。公共标题与拖动行至少高 48。 |
| 设置正文 | 全局设置各分类共享标题和正文水平边线。满宽滚动视口的滚动条位于主面板右缘，限宽 820 的正文列在视口内居中，横向内缩 32。卡片横向内缩 18。偏好行按可用宽度换行。 |

完整侧栏、头像条、窄窗整页和设置都须保留 macOS 窗口控件安全区与原生拖动区域。窄窗切换保持当前对象、未发送文字、有效滚动位置和返回焦点。右侧资料和整页详情采用与主面板一致的边框、底面和内边距。

收起 Bot Team 侧栏时，主卡片四周仍保留 `4 DIP` 外边距，顶部没有横跨窗口的空白带。可拖动页头的左上角在 macOS 窗口控件之后放置 `32 × 32 DIP` 无边框展开图标，悬停提示为「显示 Bot Team」／「Show Bot Team」。紧凑头像条只在自身宽度内为窗口控件留出空间。

外壳文字和日期使用中性辅助色。键盘焦点环在控件边界外留出 `3 DIP` 干净空气隙再描边 `2 DIP`（Paper 使用 `#2D6A4A`、Moss 使用 `#E0C65C`），输入类控件（输入框、多行文本框、Composer、复选／单选）静置呈微凹槽（浅色 `#F8F8F4`、深色 `#12130F`）并带微弱顶部内阴影，聚焦抬升回纯表面并呈现 `1 DIP` 同源边框与 `3 DIP` 半透明外光晕。每屏最多一个实心主操作（`PrimaryButton` 与高危实心确认 `DangerSolidButton` 均保留顶部微高光与按下释压感），禁用时降低对比。次操作采用 `1 DIP` 静态 `InputBorder` 边框及明确悬停／按压梯级。破坏性操作默认采用柔和红描边（`DangerButton`），不可逆归档或销毁弹窗确认采用 `DangerSolidButton`。轻操作采用 13／500 的 `LinkInk` 或辅助文字，保留可见悬停及 `3 DIP` 空气隙焦点反馈。Settings 返回按钮默认透明，标签使用正文色。文字和控件按合成后的实际背景检查对比度。

Design System 2.1 在 2.0（`1 DIP` 细边框与 9／12／16 DIP 圆角）基础上统一以下组件族与光学契约：静置输入边框采用低对比度的 1 DIP `InputBorder`（浅色 `#D4D4CE`，深色 `#3A3D36`）作为弱化底面视觉干扰的有意例外，悬停混入 26% 正文色，聚焦切换到 `#2E6B45`／`#E0C65C` 与 3 DIP 柔光晕；选中与悬停颜色过渡为 180 毫秒。共享开关沿用 MyGo 语义并对齐 `40 × 23` 轨道的 `3 DIP` 外扩焦点环；复选框（含半选）、单选框、滑块、状态胶囊、行内横幅、骨架微光条与图表组（7 日分段细柱图、80% 软预警上下文容量条、24 小时节拍轨、趋势 KPI 卡）均统一到同一双色板语义与动效节奏下，并尊重 `ReduceMotion`。模型胶囊以实线和虚线区分选择状态，品牌图标提供带圆角台面的 `BrandPedestalIcon`，单色图标随主题切换。

### 控件与输入

- 普通按钮、单行输入与选择器采用 28 高可见面。普通按钮与输入框的 squircle 区域为 16。独立结果／代码块复制使用 24 面和 16 图形，对话消息气泡不显示外侧复制图标而改由右键主题菜单复制，添加资料使用 28 面和 20 图形。图标按钮保留可访问名称与 tooltip。使用既有 RemixIcon 和 Heroicons 资源及随包许可。
- 点击区至少 32 × 32。分别检查可见面、真实命中和相邻控件遮挡。通过 Tab、方向键、Enter、Space 和 Escape 验证焦点、激活、弹层和返回。长表单的焦点进入视口，滚动到底可完成操作。
- Composer 为抬升圆角 16 卡片（1 DIP 恒定边框，聚焦切换至 `InputFocusInk` 并呈现 `3 DIP` 半透明同源外光晕，文件拖入时高亮强调色并显示投放提示），无内部分隔虚线，空态静置约 80 DIP，输入区 1–6 行平滑长高。底部工具行高 32，左侧无边框 `+` 按钮（32 × 32 点击热区，图标与上方输入文本左对齐，悬停、按压或展开时呈现 26 × 26 柔和底色）点击后在上方弹出主题浮窗菜单（多文件直选、添加文本片段，不在下方展开抽屉），瞬态提交／接收状态横向收纳在该工具行内以保证回车提交 `0 DIP` 高度零抖动，右侧 32 × 32 圆形发送／停止同位切换，停止只作用于当前对话；不显示模型切换或摘要。支持 Finder 直接拖入文件、非纯文本或超大文件路径引用兜底、卡片顶部可换行附件芯片条（带图标与移除）及毛玻璃文本片段／资料编辑弹窗。Enter 发送，Shift+Enter 换行，输入法组合期间 Enter 只确认候选。用真实 macOS IME 验证候选框、光标、选区、组合下划线和多行输入。

## Bot 对话、历史与活动

- 活动面板与 composer 共用居中的 768 DIP 内容列。活动行用状态标签区分进度，活动详情显示最新阶段和步数。执行轨迹按运行折叠，展开后显示工具、目标、已确认文件和脱敏摘要，支持分页和实时更新。活动内容独立滚动，composer 始终可操作。
- Composer 上方的紧凑活动提示按 Bot 和活动显示待答问题、技能审批、需处理事项、未知悉的结果与按规则自动回答的提示。切换提示不改变对话草稿或焦点。重连通过活动列表和详情重建提示。带选项的问题显示推荐标签和选项说明。只允许选项时必须明确选择，允许自由回答时编辑所选文字会取消该选项关联。自动回答保留独立的交付状态。
- 结果可显式标记已知悉，空闲且已结算的活动可关闭归档。关闭后仍可阅读来源对话、执行轨迹与结果。运行中的活动在没有待答问题、待审批或停止请求时可实时引导。引导回执按运行显示排队、送达、未应用和未知状态，重连只核对已经保存的指令。
- 每个 Bot 有一条连续对话。活动的 Source chat 打开原交办对话的只读记录。界面标示来源 Bot，显示加载、不可读及可用的恢复动作。Back 和 Escape 返回来源入口。读历史不调用模型。返回当前对话保留草稿、资料及发送目标。
- 向上滚动对话时，消息视口底部上方 `8 DIP` 居中浮出 `32 × 32 DIP` 圆形 `↓` 按钮，视口高度保持不变。按钮的悬停提示和可访问名称为「回到最新」／「Back to latest」。点击后滚回最新消息并聚焦 composer。
- 用户消息靠右，Bot 回复靠左，一条回复可以包含多个紧凑气泡。连续同一发送者间隔 4 DIP，换人间隔 14 DIP。非围栏代码块与非行内代码中的 `<<<NEXT>>>` 仅在行首或句末标点后切分为独立气泡（句中提及保持原文，流式未闭合后缀隐藏）；实时回复采用整泡完整弹出（生成中在左侧呈现安静的 `···` 呼吸泡，每泡写完后以 180ms 缓出进入，多泡之间保持 360ms 自然节拍；Reduce Motion 与历史重开立即全显，中断时保留已生成正文）。消息气泡外侧不渲染复制按钮，右键任意用户或 Bot 单条气泡弹出主题菜单提供 `引用`（活动对话中）与 `复制消息`，代码块右上角复制按钮与划词 `Cmd+C` 保留。引用后输入框顶部展示可取消引用条（支持 `×` 与空稿 `Escape` 清除并随草稿持久化），已发出的用户消息上方显示可点击引用条，点击平滑居中滚回并仅对被引用单条气泡展示 1.6s 柔和强调环。首次出现有效时间、跨本地日期，或距上一个时间标签已满五分钟时，在消息上方居中显示本地化时间。活动行不参与计时。来源对话沿用同一阅读样式。
- 结果和文件关联具体活动及运行。无法读取结果或文件时给出实际原因和可行操作。未知发送或回答保留原记录供核对。持久化与恢复按产品协议执行。[产品协议](product-protocol.md)
- 所有 Bot 共享同一套空对话呈现：居中的 `48 × 48` 无底框地质岩块双层头像、问候标题与可选用途说明，输入框正上方紧贴左对齐无边框的灵感提示行（点击直接填入草稿并聚焦输入框，不自动发送）。灵感提示对所有 Bot 走同一数据管线：优先使用资料中保存的 `starterPrompts`（最多 4 条），其次在已有旧版 `PandoraBox` 资料上回退本地化默认提示，或在普通 Bot 上取最近 2 条带日期工作日志与用途拼装；三者皆空时保持干净空白，不填充通用套话。
- Bot 按名称和用途查找。内置 `PandoraBox` 与普通 Bot 共享一致的列表行外观（不显示 `Built-in`／`内置` 标签），显示时固定在 Bot Team 顶部并拒绝归档／恢复；用户可在 `Settings → General`、右键菜单或资料页底部自由切换其在 Bot Team 中的显示／隐藏（列表为空时提供「显示 PandoraBox」恢复入口），隐藏期间仍可通过新建 Bot 弹窗的「用 PandoraBox 对话创建」随时呼出。头像采用冻结的 8 种地质岩块双层矢量设计（Body 轮廓叠加严格等大双眼 Eyes 图层）与 9 种高原釉彩双主题配色（含深色模式下反转为岩白的玄墨色；`PandoraBox` 固定为双叠石配炽陶橙，自定义 Bot 按稳定 ID 独立哈希分配形状与釉彩），在对话页头（`28 × 28`）、完整侧栏（`28 × 28`）、收起态头像条（`24 × 24`）承载柔和圆角底座（82% 岩石内缩，`#F2F2EC`／`#242620` 台面与微细边线，资料页 `32 × 32` 与空态 `48 × 48` 保持独立裸石展示），并统一采用「混合微光底座状态环 + 2 DIP 同底切边角标（方案 C）」状态语言（按 `已归档 > 等你回答／需要处理 > 正在回复 > 后台任务 > 1.8s 完成回执 > 空闲` 优先级：空闲态保持干净底座、已归档降至 56% 不透明度并去饱和 55% 配灰色减号角标、正在回复叠加 1.5s 柔和呼吸绿环与绿色三点跳动角标并尊重 Reduce Motion、后台任务用净底座配主色旋转角标、等待处理叠加稳态琥珀环与感叹号矢量角标、完成短显 1.8s 绿色对勾角标后归静）；角标切边随宿主行底色（Rail／Selection／Hover／Background）动态对齐，页头右侧按需独立呈现可点击任务／待答直达动作、解耦的全局连接提示，以及单个无边框的 `···`（「Bot 概览 / Bot overview」）折叠菜单按钮（收拢当前 Bot 的「活动」「后台工作」「终端会话」「计划工作」与「Bot 资料」，并在菜单项旁提示活跃数量），不再并排显示常驻文本按钮、`Ready` 或旧 `Role`；从概览菜单、左侧右键菜单或 Dock 打开的「后台工作」与「终端会话」统一在右侧按需展开的自适应抽屉内呈现（宽窗与对话并排、窄窗切至应用内页，从根列表返回或按 `Escape` 即收回纯对话并恢复来源焦点，从 Bot 资料内入口进入则返回 Bot 资料）。右键左侧 Bot 列表中的整行打开管理菜单（存在待确认学习时提示数量）。资料页展示基础档案、可选多行「灵感提示」、行为设定与按 Bot 隔离的「记忆与学习」（待确认学习的批准／忽略、持久规则的增删改、带日期工作日志的检索与删除），并将归档／恢复（或 `PandoraBox` 的显示／隐藏）操作固定在底部页脚，避免异步加载移动按钮位置。保存反馈紧邻保存操作。macOS 应用图标（`assets/icons/AppIcon.icns` 及未打包运行时的 `icons.DockPNG`）采用浅底暖宣「双石相托」`暖宣玄朱` 造型（`#FBF9F1`→`#EAE5D3` 宣纸圆角方底、`#2D302C` 玄墨切面下石配等大 `#FFFDF4` 豆豆眼与 `#E4542E` 朱砂红泥斜托上石）。
- 创建 Bot 时，以 12 DIP 模糊加一层主题色遮罩弱化工作台。表单保持不透明，圆角 16 DIP，并保留按 Escape、取消和单击背景的返回方式。创建 Bot、素材、提供方和能力弹窗共用毛玻璃遮罩、细边框和圆角。

## Settings、连接与恢复

- 设置页使用统一标题、导航和偏好行。General 包含 Bot Team、外观、语言与工作台数据。Advanced 进入时展示运行状态，启动失败时展开诊断。每个 Bot 的资料编辑器从左侧列表进入，保存对象与菜单对应的 Bot 一致。
- 「提供方」与「路由」共享居中的 820 DIP 滚动内容区和顶部状态栏。已有账户按优先级排列，可在行内调整顺序，目录接着显示本地与自定义和常用服务商。窄内容区从三列切为两列。有账户时常用服务商默认收起，预览仍显示品牌图标。无账户且有旧版配置时显示导入横幅，只预填非密钥字段。
- 目录由内置 `internal/connection/catalog/providers.json` 和 `catalog/icons/` 定义。应用打开连接设置时按目录名顺序读取 profile 下的 `provider-plugins/*/providers.json`，最后应用 profile 根目录的 `providers.json`。同 ID 的字段可覆盖，`hidden` 可隐藏预设。插件图标放在同级 `icons/`，无匹配图标时使用内置自定义图标。
- 添加和编辑共用 616 DIP 的毛玻璃弹窗。正文滚动，标题和保存操作固定。保存的密钥以遮蔽条显示，可更换或撤销。模型池支持测试同步、全选、全不选、自定义 ID、上下文容量标签和仅作备用。取消、Escape 或单击背景会保留表单草稿并返回来源焦点。待应用时顶部提供应用入口，弹窗打开后以「保存并应用」为主操作。
- 内置服务商预设的默认模型为空。打开预设后，可点击「获取可用模型」读取服务商的 `/models` 列表，表单会优先自动选择推荐的聊天模型。也可以直接输入模型 ID，或手动添加第一个模型作为默认值。
- 路由页显示省钱、均衡和优先质量策略。对话、编程、推理和轻量辅助分别支持自动、固定模型、固定提供方及模型，并显示生效路由、切换原因和健康状态。保存的策略和固定项在应用后生效。失效的固定项保留可见，用户可改为自动或选择其他路由。
- 凭据或路由不可用时，未派发的对话保留草稿和引用，并提供连接设置入口。冷却提示显示可重试时间。活动问题的已保存回答继续可读，并注明交付暂停原因。
- 能力设置集中管理技能与 MCP 服务，使用分栏、状态栏与 616 DIP 的毛玻璃表单。窄窗将列表放在详情上方。全局技能可预览和编辑，本机技能发现与 MCP 服务启停使用共享开关。MCP 凭据用密码输入，留空可保留已保存值，清除需明确选择。服务详情展示测试发现的工具、工具权限提示和当前连接池。
- Bot 资料中的内置工具预设、技能挂载和 MCP 工具范围随资料一起保存。自定义内置工具与 MCP 工具白名单使用共享选择胶囊，实线与虚线区分选择状态。Bot 私有技能可在资料内检查、提升为全局技能或删除。可执行技能的审核弹窗展示具体脚本、文件、工作区、网络来源及凭据引用。授权绑定当前 Bot 和所审核的版本，正在等待授权的活动使用该次请求的版本。资料管理操作固定在底部。悬停与选择反馈沿用 180 毫秒过渡，主题切换时胶囊和状态标签的文字与底色同步更新。

### 外观与语言

General 使用三段式控件切换跟随系统、浅色和深色，并在其下显示适用的自定义主题选择器。导入和重新加载本地主题使用描边按钮。保持当前会话、编辑、选区和有效滚动位置。区分本次应用与保存结果，保留用户选择。语言沿用系统、简体中文和 English 的原生偏好。界面文案、日期、时间和数字随语言显示，身份、草稿、用户与 Bot 内容保留原文。用真实窗口验证主题和语言切换、字体回退、系统选择器及重开。
