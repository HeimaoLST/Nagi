## 原生窗口与布局

采用 Bee 外观及已批准的第一阶段可读性、动作层级与页面结构修正。尺寸均为 DIP。`workspace.go` 定义分栏，`view.go` 组装主面板，`navigation.go` 组装只读对话，`settings_page.go` 组装设置。

| 布局 | 当前结构及验收边界 |
| --- | --- |
| 工作台 | 透明侧栏置于外壳上，主面板留 4 的外边距和 1 的边框。侧栏包含 Bot 搜索、列表、新增和底部设置。普通侧栏默认 238，可调 180–420。分隔线可拖动及通过键盘操作。响应布局保留用户设置的栏宽。 |
| Bot 资料 | 从 1180 起完整侧栏、对话、资料同屏。900–1179 使用 56 宽头像条，资料栏最小 300。低于 900 使用带返回的应用内整页。分栏内用 X 关闭资料。资料栏默认 340，通常可调 280–440，也受可用空间约束。 |
| 对话区 | 恢复通知、阅读和 composer 共享居中的 768 最大列宽。页头横向内缩 16、纵向内缩 12，底部使用 1 DIP 分隔线。用户消息上限 752。分栏算法的中心预算为 512。C-4 要求 960 × 640 同时显示资料与对话时，净可编辑宽度至少 440。720 × 640 检查活动打开时 composer 仍可聚焦、输入和发送。 |
| 设置 | 常规侧栏宽 248，导航组左右内缩 8，行填满组。小于 640 的设置布局使用可换行顶部导航。主面板四周留 8，公共标题与拖动行高 40。 |
| 设置正文 | 全局设置各分类共享标题和正文水平边线。满宽滚动视口的滚动条位于主面板右缘，限宽 820 的正文列在视口内居中，四周内缩 32，净宽最大 756。分组内缩 16。偏好行按自身可用宽度换行。 |

完整侧栏、头像条、窄窗整页和设置都须保留 macOS 窗口控件安全区与原生拖动区域。窄窗切换保持当前对象、未发送文字、有效滚动位置和返回焦点。右侧资料和整页详情采用与主面板一致的边框、底面和内边距。

### 控件与输入

- 普通按钮、单行输入与选择器采用 28 高可见面。普通按钮与输入框的 squircle 区域为 16。消息复制使用 24 面和 16 图形，添加资料使用 28 面和 20 图形。图标按钮保留可访问名称与 tooltip。使用既有 RemixIcon 和 Heroicons 资源及随包许可。
- 点击区至少 32 × 32。分别检查可见面、真实命中和相邻控件遮挡。通过 Tab、方向键、Enter、Space 和 Escape 验证焦点、激活、弹层和返回。长表单的焦点进入视口，滚动到底可完成操作。
- Composer 最小高 120、圆角 16、边框 1、工具行高 42。资料、只读模型摘要以及发送或停止都在容器内。发送与停止共用位置，停止只作用于当前对话。Enter 发送，Shift+Enter 换行，输入法组合期间 Enter 只确认候选。用真实 macOS IME 验证候选框、光标、选区、组合下划线和多行输入。

## Bot 对话、历史与活动

- 用户在当前对话交办。活动列表和详情位于所选 Bot 的对话列。每项明确显示目标、进度和待答问题，补充、回答、停止、结果和文件的作用对象可辨。停止一次运行、收到结果和事项完成分别呈现。活动可独立滚动，composer 仍可操作。
- Previous chats 按当前 Bot 分页。用可辨文字摘要及可用时间标识对话。活动 Source chat 打开对应来源对话。两处沿用只读消息样式。Back 和 Escape 返回原列表行或来源入口。显示加载、不可读及可用的恢复动作。读历史不调用模型。返回当前对话保留草稿、资料及发送目标。
- 结果和文件关联具体活动及运行。无法读取结果或文件时给出实际原因和可行操作。未知发送或回答保留原记录供核对。持久化与恢复按产品协议执行。[产品协议](product-protocol.md)
- Bot 按名称和用途查找。头像使用可辨首字母及按名称稳定分配的底色。页头的名称、状态和已有职责分别呈现。右键左侧 Bot 列表中的整行打开管理菜单。资料页使用实心保存按钮、描边的保存并开始新对话按钮以及错误色描边归档按钮。保存反馈紧邻保存操作。资料保存作用域和当前对话独立。

## Settings、连接与恢复

- General、Connection 和 Advanced 共用标题、章节、分组和偏好行。分组用留白及单层细线组织，最后一项后留滚动空间。导航可见面 28，标签 12／16，图标 14，图文间距 8。General 的语言和自定义主题使用选择器。每个 Bot 的资料编辑器从左侧列表进入，保存对象与菜单对应的 Bot 一致。
- 首用连接使用 GUI 输入端点、密钥和模型，保存、应用和测试前需提供工作目录。协议使用两段式控件。容量行默认显示摘要，展开可选择 1–4 个并行任务和三组 token 预设。保留超出预设的已保存任务数和自定义 token 精确值。工作目录依次提供原生选择和手动输入入口。Test 使用当前表单快照，通过 tooltip 提示可能计费。保存并应用或应用已保存配置是表单主操作，保存、测试和反馈在同一处。原始诊断默认折叠，内容有界且脱敏。Advanced 进入时展示运行状态，启动失败时展开诊断。

<a id="rp1-rp2-implementation-20261111"></a>

- 断连通知使用对话列内的一张恢复卡。运行时与同一断连相关的会话诊断共用折叠详情，保留打开连接设置的动作。存在可核对连接与目标时才呈现对应核对操作。测试总体失败、明确拒绝和未知交付分别提示。[v1 用户操作](../requirements/desktop.md#v1)

<a id="c8-data-recovery-implementation-20261111"></a>

- Workbench data 提供当前 profile 的恢复备份，并在当前资料不可读时提供暂停恢复。导出与恢复是描边按钮，备份范围默认折叠。恢复流程区分选择、预览、确认、存盘结果和退出重开。说明实时工作阻塞、兼容性、原件保存以及历史和文件可用性。重开保留身份、草稿及未知状态，且不重放。[当前 profile 协议](product-protocol.md#current-profile-admission)

### 外观与语言

General 使用三段式控件切换跟随系统、浅色和深色，并在其下显示适用的自定义主题选择器。导入和重新加载本地主题使用描边按钮。保持当前会话、编辑、选区和有效滚动位置。区分本次应用与保存结果，保留用户选择。语言沿用系统、简体中文和 English 的原生偏好。界面文案、日期、时间和数字随语言显示，身份、草稿、用户与 Bot 内容保留原文。用真实窗口验证主题和语言切换、字体回退、系统选择器及重开。
